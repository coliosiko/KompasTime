# KompasTime

KompasTime учитывает время работы с документами КОМПАС‑3D. История хранится в самих документах, а сводные отчёты можно выгружать в Excel.

## Установка и совместимость

1. Закройте все окна КОМПАС‑3D.
2. Распакуйте установочный ZIP целиком и запустите `install.cmd` из распакованной папки. Для обновления используется тот же скрипт.
3. Запустите КОМПАС‑3D. Команды находятся в **Приложения → KompasTime**. При первом запуске учёт включён.

Нужны Windows x64, .NET Framework 4.8 и КОМПАС‑3D x64. Установщик подключает приложение ко всем обнаруженным версиям начиная с v23. Для отдельных версий можно запустить, например, `install.cmd -Versions 23,24` из командной строки Windows.

| Версия КОМПАС‑3D | Статус |
| --- | --- |
| v25 | Проверено в КОМПАС‑3D |
| v23, v24 | Основные вызовы API сверены с SDK. Запуск приложения ещё не проверен |
| Новее v25 | Установщик обнаруживает новые версии. Совместимость проверяется отдельно |

Для удаления закройте КОМПАС и запустите `uninstall.cmd`. Он удалит приложение и его настройки. История в CAD-файлах и выгруженные отчёты сохранятся.

## Учёт времени

Время начисляется для активного документа, доступного для записи, пока КОМПАС на переднем плане. Просмотр документа тоже учитывается. После трёх минут бездействия учёт приостанавливается и возобновляется при следующем вводе.

Наведите указатель на значок часов в рабочей области. **К сохранению** показывает ещё не записанное время, **Сохранено в файле** — общий итог из истории. Учёт и видимость значка переключаются отдельно. В **Настройках** можно изменить порог бездействия, угол и масштаб значка, а также включить или отключить учёт при запуске КОМПАС.

## Сохранение и история

Время записывается вместе со штатным сохранением CAD-документа. Если КОМПАС пропустил сохранение неизменённого файла, время остаётся в счётчике **К сохранению**. При закрытии без записи накопившееся время теряется.

История переносится вместе с CAD-файлом. KompasTime читает и записывает её через API 7 в пользовательском хранилище `KompasTime.WorkHistory`.

В **Истории** видны автор Windows, дата и время последнего сохранения и длительность сеанса. Повторные сохранения одного открытого документа обновляют одну строку. После повторного открытия начинается новый сеанс. Удаление строки применяется при следующем сохранении. При **Сохранить как** под другим именем в историю нового файла попадает только ещё не записанное время.

## Отчёты

- **Сводные данные** доступны для сохранённой сборки `.a3d`. Отчёт показывает дерево связанных документов и сохранённое время по каждому файлу. Общий итог включает саму сборку и считает каждый путь один раз.
- **Отчёт по файлам** формирует плоский список для выбранных документов. Нажмите **Добавить…** и выделите файлы и папки, перетащите их из Проводника или вставьте через `Ctrl+V`. Папки просматриваются с подпапками. Поддерживаются `.m3d`, `.a3d`, `.t3d`, `.cdw`, `.spw`, `.frw` и `.kdw`. Список хранит пути. Окно можно держать открытым во время работы в КОМПАС.

В обоих отчётах можно остановить расчёт и экспортировать готовый результат в `.xlsx`. Отчёты читают сохранённые трудозатраты и не меняют исходные документы.

## Сборка из исходников

Откройте `KompasTime.sln` в Visual Studio с компонентами настольной разработки .NET и пакетом разработки .NET Framework 4.8. Для сборки нужен установленный SDK КОМПАС‑3D с зарегистрированными COM-библиотеками. Соберите **Release | x64**. Для установочного ZIP возьмите `bin/x64/Release/net48/KompasTime.Pane.dll`, файлы из `Installer`, README и LICENSE.
