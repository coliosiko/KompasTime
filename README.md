# Трудозатраты в КОМПАС-3D

Приложение работает в отдельном окне Windows и использует API 7 запущенного КОМПАС-3D. История времени хранится внутри CAD-файла в пользовательском хранилище.

## Запуск

Откройте `KompasTime.sln` в Visual Studio и нажмите **F5**. Для сборки нужны настольная разработка .NET, пакет разработки .NET Framework 4.8 и установленный КОМПАС-3D с зарегистрированной библиотекой API 7. Сборка рассчитана на x64. При сборке из терминала используйте MSBuild из Visual Studio.

## Что посмотреть

- Для проверки в КОМПАС откройте деталь или создайте новую. Учёт запускается автоматически, когда доступный для записи документ активен. Время просмотра входит в общий таймер.
- Для просмотра окна без КОМПАС можно запустить `KompasTime.exe --demo`.
- Окно КОМПАС должно быть на переднем плане для начисления времени. При смене активной вкладки таймер относится к выбранному документу. Интервал бездействия по умолчанию составляет три минуты.
- Имя автора берётся из Windows. SID можно увидеть во всплывающей подсказке на имени.

## Сохранение и продолжение учёта

- Сохраните документ обычной командой КОМПАС. Когда КОМПАС сообщает о начале сохранения, приложение добавляет накопленное время. Карточка **Сохранено в файле** показывает общий итог, а **К сохранению** показывает время после последней записи.
- Если КОМПАС пропускает сохранение файла без изменений, накопленное время остаётся в карточке **К сохранению** до фактической записи или закрытия документа.
- При повторном открытии приложение читает итог и сразу начинает новый сеанс для активного документа. При закрытии без сохранения время этого сеанса пропадает, файл остаётся прежним.
- При **Сохранить как** под другим именем новый файл получает отдельную историю. В неё попадает время, которое ещё не было записано. Исходный файл сохраняет свою историю.
- Внутри файла хранятся версия формата, идентификатор документа, SID и имя автора, время сохранения и учтённые секунды. Отдельно записанное время просмотра из прежней версии входит в сохранённый итог.

## История

- Кнопка **История** открывает таблицу активного документа. В ней показаны автор, местная дата и время последнего сохранения и итог сеанса.
- Последовательные сохранения открытого документа обновляют одну строку. Переключение вкладки и пауза по бездействию её не разбивают. После закрытия и повторного открытия следующий сеанс получает отдельную строку. Ранее сохранённые строки сохраняются в исходном виде.
- Выберите строку и нажмите **Удалить запись**. КОМПАС предложит сохранить изменение истории, даже если геометрия не менялась. При закрытии без сохранения строка останется в файле. Строки создаются автоматически таймером. Если удалить строку текущего сеанса, новое время попадёт в новую строку.

## Сводный отчёт по сборке

Откройте сохранённую сборку `.a3d` и нажмите **Сводный отчёт**. В дереве отображаются имена файлов и сохранённые трудозатраты каждого файла. Итог учитывает корневую сборку и каждый уникальный путь один раз. Повторное вхождение можно увидеть в своей ветви. Уже раскрытый в другой ветви состав повторно не строится.

Отчёт следует по ссылкам КОМПАС, включая вложенные сборки и связанные документы поддерживаемых форматов. Если файл не найден, недоступен или не содержит учёта, это видно в дереве. Связанные документы без ссылки из состава автоматически не ищутся.

Чтение выполняется в фоне. Кнопка **Остановить** прекращает обход после завершения текущего вызова КОМПАС. Сводные данные остаются в окне отчёта. Файлы открываются для чтения, отчёт их не сохраняет.

После расчёта нажмите **Экспорт в Excel**. В `.xlsx` попадут всё дерево, включая свёрнутые ветви, и итог по уникальным файлам. Трудозатраты записываются как числовые длительности, уровень вложенности указан в отдельной колонке.

## Границы прототипа

Время, которое ещё не сохранено, хранится в памяти. Восстановление сеанса после сбоя, выбор профиля автора и вывод итога в стандартные свойства КОМПАС пока не реализованы.

На КОМПАС-3D v25 проверены деталь `.m3d` и чертёж `.cdw`. Оба типа прошли первое сохранение, повторное открытие, два последовательных сохранения, закрытие без сохранения с неизменным SHA-256 и «Сохранить как». Другие типы документов и совместимость с v23 требуют проверки.
